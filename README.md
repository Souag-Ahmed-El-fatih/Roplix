
# roplix kernel
----------------

The roplix kernel provides the foundation for any Roblex operating system
it has the capability to manage your device's hardware software and other components.

# Quick facts about the project :
license : GPLv3
Supported architectures : x86
kernel type : Monolithic
Lead Project Manager : souag ahmed el fatih

# How to build the project

build kenrel & drivers  & linker kernel :
  make

setup build :
 make setup

build entry :
  make build_entry

build kernel:
  make build_kernel

linker kernel & build elf kernel :
  make build_elf
